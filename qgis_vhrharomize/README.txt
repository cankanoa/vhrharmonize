VHRHarmonize QGIS Plugin
========================

Open VHRHarmonize from the Plugins menu or toolbar. Base and optional Python
dependencies can be installed from editable commands on the Setup tab. Edit
persistent provider, HPC, and Slurm configuration files, then use the persistent
interactive shell on the Run tab.
Enable Use Conda on the Setup tab to create a named environment and generate
all dependency and Run preset commands for that environment automatically.
Preset and Setup buttons place editable text directly in the terminal input.
The shell retains its working directory, environment, and process state, and
accepts commands, responses, passwords, Ctrl+C, and Ctrl+D directly.
Linux and macOS use a real pseudo-terminal; Windows uses a persistent command
shell through standard input and output.
